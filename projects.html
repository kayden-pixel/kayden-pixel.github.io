PROJECT 01 · MINECRAFT
Public release

OmniPanel

My biggest public Minecraft plugin. OmniPanel is an all-in-one server administration platform for modern Paper/Purpur servers. It combines staff tools, player management, Punishment X, Command Hub V5, regions, ranks, kits, homes, AutoMod, authentication, alerts, diagnostics, Multiverse world controls, Velocity networking and DiscordSRV integration around one main /panel workflow.

Explore the engineering details
  • Permission-gated inventory menus and plugin integrations form a central operations surface.
  • Admin systems coordinate worlds, player actions, ranks, protections and diagnostics.
  • Public Modrinth releases offer an installation path; actual version compatibility varies.
Hybrid inventory GUIs + native Minecraft dialogs for forms, confirmations and settings
Paper/Purpur 26.2–26.3 support with Java 21-compatible plugin bytecode
Public API for other plugins to open menus, create alerts, access punishments, homes, regions and events
Integrations include LuckPerms, PlaceholderAPI, Vault, WorldGuard, Geyser/Floodgate, TAB and DecentHolograms

PROJECT 02 · SECURITY
Private source

ModAI

A Discord security/moderation system I have rebuilt and upgraded through many versions. The core idea is panel-first: keep the public command list small, put the real controls in the panel, and keep security systems such as anti-nuke, anti-raid, anti-leak, AutoMod, role/staff protection, incidents, recovery and diagnostics connected instead of split across random commands.

  • Event ingestion and incident deduplication reduce duplicate enforcement.
